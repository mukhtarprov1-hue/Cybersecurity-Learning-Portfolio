# Contributing

Thanks for helping improve this learning portfolio.

## Before opening a change

1. Keep each project self-contained under `projects/`.
2. Include a focused README with requirements, build/run commands, test instructions, and known limitations.
3. Add reproducible tests for changed behavior.
4. Run the local checks described by the project before proposing a change.
5. Use sample data. Never commit passwords, tokens, keys, private course content, private invitation links, or personal data.
6. Use clear commit messages that describe the change.

## Scope

This repository is a curated educational portfolio, not a dump of every class file. Do not add material unless it is safe to publish, relevant to the portfolio, and permitted by its license or course terms.
