## 2. البناء

من داخل مجلد `04-log-file-parser`:

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror -O2 log_parser.c -o log_parser
```

## 3. إنشاء سجل اصطناعي وتشغيل الأداة

```bash
python3 samples/create_sample.py
./log_parser samples/sample.log FAILED
./log_parser samples/sample.log 404
```

المتوقع عند `FAILED`: سطران مطابقان (رقما 2 و5)، و`Total alerts: 2`. والمتوقع عند `404`: سطر واحد (رقم 4)، و`Total alerts: 1`.

## 4. الاختبارات الآلية

```bash
python3 tests/run_tests.py ./log_parser
```

تتضمن الاختبارات حالات الملف المفقود والفارغ وعدم وجود تطابق، وحساسية الأحرف، والسطر الطويل الذي يعبر حد مخزن الإدخال، والملف المكوّن من 6000 سطر.

## 5. نقاط المراجعة الفنية

- التحقق من استخدام `fopen(..., "r")`.
- التحقق من القراءة بـ `fgets()` والبحث بـ `strstr()`.
- ملاحظة أن العداد يزيد مرة واحدة لكل سطر منطقي مطابق.
- التأكد من أن السطور الطويلة لا تخلط بين عدد استدعاءات `fgets()` وعدد أسطر الملف.
- التأكد من إظهار ملخص `Total alerts` حتى في حالة عدم وجود مطابقات.
