# التقرير العملي — التكليف السابع
## أداة تحليل السجلات الأمنية المؤتمتة (Automated Log Analyzer)

**اللغة:** Python  
**المجال:** Security Operations Center (SOC) / Web Log Analysis  
**نطاق التنفيذ:** تحليل ملفات سجلات نصية محلياً، دون اتصالات شبكية.

## 1. الهدف

إنشاء أداة تقرأ سجل خادم ويب سطراً بسطر وتبحث عن مؤشرات محددة لهجمات SQL Injection وPath Traversal باستخدام التعبيرات النمطية. عند العثور على مؤشر، تطبع تنبيهاً يتضمن نوع الهجوم، رقم السطر، عنوان IP، الدليل المطابق ومقتطفاً مختصراً من السجل. وفي النهاية تعرض ملخصاً بعدد الأسطر المفحوصة والتنبيهات حسب الفئة.

## 2. آلية التنفيذ

### 2.1 القراءة المتدفقة

يستخدم البرنامج مدير السياق with مع Path.open()، ثم يمر على كائن الملف مباشرة. لا يستدعي read() لتحميل كامل الملف، ما يسمح بمعالجة ملفات أكبر مع إبقاء استهلاك الذاكرة مرتبطاً بعدد التنبيهات المسجلة بدلاً من حجم الملف الكامل.

### 2.2 قواعد الكشف

تُعرّف القواعد باستخدام re.compile(..., re.IGNORECASE) وتُطبق بواسطة Pattern.search().

| الفئة | المؤشرات التي يغطيها الإصدار |
|---|---|
| SQL Injection | UNION SELECT، مقارنات Boolean من نوع OR/AND، الدوال SLEEP() وBENCHMARK()، LOAD_FILE() وINTO OUTFILE. |
| Path Traversal | التسلسل ../ أو ..\ وصيغ URL-encoded الشائعة مثل %2e%2e%2f و%2e%2e%5c. |

يفحص البرنامج السطر الأصلي ونسخة URL-decoded منه بواسطة unquote_plus للمساعدة على اكتشاف بعض الحمولات المشفرة. وتُحفظ عينة السجل الأصلية في التنبيه للمراجعة.

### 2.3 استخراج عنوان المصدر

يفترض البرنامج أن الحقل الأول من السجل هو عنوان العميل، وهو تنسيق شائع في سجلات Apache/Nginx. يتحقق من القيمة باستخدام ipaddress.ip_address() ويدعم IPv4 وIPv6. إذا لم يكن الحقل الأول عنوان IP صالحاً، يستخدم القيمة UNKNOWN بدلاً من تخمين عنوان من بقية السطر.

### 2.4 التنبيهات والملخص

لكل فئة تطابق على السطر، يطبع البرنامج تنبيهاً يتضمن:
- نوع الهجوم.
- رقم السطر.
- عنوان IP المصدر كما سجله الخادم.
- النص المطابق.
- مقتطفاً من السجل.

إذا طابق السطر نفسه أكثر من فئة، يصدر تنبيهاً مستقلاً لكل فئة. ويحسب الملخص عدد الأسطر المفحوصة، والأسطر المشبوهة المميزة، وإجمالي التنبيهات، وعدد التنبيهات لكل نوع.

## 3. ملفات المشروع

| الملف | الوظيفة |
|---|---|
| log_analyzer.py | البرنامج الرئيسي وقواعد Regex وتحليل السجلات والتقارير. |
| tests/test_log_analyzer.py | اختبارات كشف الهجمات واستخراج IP والملخص وأخطاء الملفات. |

| TASK_SPEC_AR.md | توثيق متطلبات التكليف بالعربية. |
| docs/TEST_RESULTS.md | أوامر ونتائج الاختبارات في بيئة إعداد المشروع. |

## 4. طريقة التشغيل

تشغيل عينة السجل:

    python log_analyzer.py samples/sample_access.log

تحليل سجل يملكه المستخدم أو لديه إذن لتحليله:

    python log_analyzer.py "C:\Logs\access.log"

حفظ التقرير بصيغة JSON:

    python log_analyzer.py "C:\Logs\access.log" --format json --output report.json

فحص الصياغة والاختبارات:

    python -m py_compile log_analyzer.py tests/test_log_analyzer.py
    python -m unittest discover -s tests -v

## 5. التحقق باستخدام بيانات تجريبية

يحتوي samples/sample_access.log على ستة أسطر اصطناعية:
- سطران طبيعيان.
- مؤشرا SQL Injection.
- مؤشرا Path Traversal.

النتيجة المتوقعة لهذه العينة:
- الأسطر المفحوصة: 6.
- الأسطر المشبوهة: 4.
- إجمالي التنبيهات: 4.
- SQL Injection: 2.
- Path Traversal: 2.

عناوين IP في العينة من نطاقات مخصصة للتوثيق والأمثلة، ولا تمثل مصادر حقيقية.

## 6. اختبارات الوحدة

تغطي مجموعة الاختبارات 15 حالة، تشمل كشف UNION SELECT وBoolean SQL Injection وSLEEP()، وكشف Path Traversal الصريح والمشفر، واستبعاد السجلات الطبيعية، واستخراج IPv4 وIPv6، وترقيم الأسطر، ومعالجة الملفات المفقودة، وصحة تقارير النص وJSON.

## 7. اعتبارات الدقة والحدود

- Regex-based detection تعتمد على مؤشرات محددة؛ لا تكشف كل أشكال الهجمات أو جميع طرق التمويه.
- وجود مؤشر في سجل HTTP لا يثبت نجاح الهجوم أو حدوث اختراق.
- بعض النصوص الشرعية قد تشبه الحمولات الهجومية؛ التنبيه يحتاج إلى مراجعة سياقية من محلل SOC.
- يفترض استخراج IP أن الحقل الأول هو عنوان العميل. تنسيقات السجلات المخصصة قد تتطلب parser مختلفاً.
- لا تقوم الأداة بإجراء اتصالات شبكية أو بتعديل ملفات السجل.
- لا تستخدم هذه الأداة كبديل عن SIEM أو WAF أو التحليل الجنائي الكامل.

## 8. الخلاصة

يوفر المشروع محللاً تعليمياً لسجلات خوادم الويب، يطبق Regex للكشف عن مؤشرات SQL Injection وPath Traversal، ويربط كل تنبيه برقم السطر وعنوان IP المسجل، ويقدم ملخصاً نصياً أو JSON. تم اختباره ببيانات اصطناعية ويحتفظ بحدود الكشف موضحة لتجنب التفسير الخاطئ للنتائج.
