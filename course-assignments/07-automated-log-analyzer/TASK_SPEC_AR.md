# التكليف السابع: أداة تحليل السجلات الأمنية المؤتمتة
## Automated Log Analyzer

**مسار البرمجة:** الأمن السيبراني — Python

## 1. وصف التكليف

تطوير سكريبت بلغة Python يساعد محلل مركز العمليات الأمنية (SOC) على قراءة ملفات سجلات خوادم الويب النصية وتحليلها تلقائياً. يستخدم البرنامج التعبيرات النمطية (Regular Expressions / Regex) لاكتشاف مؤشرات لمحاولات هجوم، ومن أمثلتها SQL Injection مثل UNION SELECT، وPath Traversal مثل ../../etc/passwd.

عند اكتشاف مؤشر، يطبع البرنامج تنبيهاً أمنياً يتضمن نوع الهجوم، ورقم السطر، وعنوان IP المسجل في السجل.

## 2. خطوات الإنجاز

1. فتح ملف السجل باستخدام with open(...) أو Path.open(...).
2. قراءة الملف سطراً بسطر، وعدم تحميل الملف كاملاً إلى الذاكرة.
3. تعريف أنماط Regex باستخدام re.compile(...).
4. استخدام re.IGNORECASE لتجاهل اختلاف حالة الأحرف.
5. استخدام Pattern.search() أو re.search() للبحث داخل كل سجل.
6. تكرار الفحص على جميع السجلات.
7. طباعة تنبيه يتضمن نوع الهجوم ورقم السطر وعنوان IP.
8. عرض ملخص نهائي بعدد الأسطر المفحوصة والتنبيهات وتوزيعها حسب النوع.

## 3. معايير القبول

- اكتشاف مؤشرات SQL Injection المحددة في الكود والاختبارات.
- اكتشاف مؤشرات Path Traversal، بما فيها أمثلة URL-encoded.
- استخراج عنوان IP الصحيح من سجلات الوصول الشائعة.
- إظهار رقم السطر ونوع الهجوم وعنوان المصدر لكل تنبيه.
- تجاهل السجلات الطبيعية التي لا تطابق الأنماط المحددة.
- عرض ملخص واضح بالأعداد الإجمالية والتوزيع حسب نوع الهجوم.
- معالجة أخطاء قراءة الملفات ورسائل الاستخدام دون انهيار غير معالج.
- توفير اختبارات قابلة لإعادة التشغيل وبيانات تجريبية لا تحتوي على معلومات حقيقية.

## 4. حدود التفسير

الأنماط النمطية تكشف مؤشرات وليست حكماً نهائياً بأن الهجوم نجح. يجب على محلل SOC مراجعة سياق التنبيه. كما أن عنوان IP هو العنوان المسجل في ملف الخادم، ولا يثبت وحده هوية المهاجم.
