# دليل المدرب — مراجعة التكليف 14

1. افتح public/index.html وتحقق من وجود حقل المدخل وزري العرض.
2. لاحظ الحمولة الافتراضية في textarea: IMG مع onerror يرسل علامة إثبات فقط.
3. اضغط «تشغيل العرض الآمن». يجب ظهور السلسلة كاملة كنص حرفي دون إنشاء عنصر IMG داخل حاوية النتيجة.
4. اضغط «تشغيل العرض غير الآمن». يتم تفسير السلسلة عبر innerHTML داخل iframe معزول؛ يظهر مؤشر DOM-XSS PROOF عند تنفيذ الحدث.
5. افحص iframe: sandbox="allow-scripts" فقط؛ لا يوجد allow-same-origin. لذلك لا يستطيع الإطار قراءة DOM أو كوكيز الصفحة الأم.
6. راجع CSP داخل srcdoc: تمنع connect-src وكل الموارد الخارجية، وتسمح data image فقط للحمولة.
7. راجع tests/dom-xss.spec.js ونتيجة GitHub Actions للتأكد من التحقق الآلي في متصفح Chromium.

## المبدأ

textContent هو الخيار الصحيح لإدراج النصوص غير الموثوقة. innerHTML نقطة تحليل HTML وقد تؤدي إلى XSS إذا استخدمت مع مدخلات غير موثوقة.
