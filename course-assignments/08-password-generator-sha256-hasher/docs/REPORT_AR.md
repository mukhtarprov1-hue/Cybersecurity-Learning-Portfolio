# التقرير العملي — التكليف الثامن
## أداة مولد كلمات السر وحساب التجزئة SHA-256
**Password Generator & SHA-256 Hasher**

**لغة البرمجة:** Python  
**بيئة التحقق الفعلية:** Windows PowerShell  
**تاريخ التحقق:** 12 نوفمبر 2026  
**الاعتماديات:** مكتبات Python القياسية فقط.

## 1. الهدف

تطوير برنامج يقدم خدمتين: توليد كلمات مرور عشوائية آمنة تشفيرياً بمجموعات أحرف متنوعة وطول يحدده المستخدم، وحساب قيمة SHA-256 لنص UTF-8 وعرضها بصيغة Hexadecimal.

## 2. مولد كلمات المرور

يعتمد البرنامج على أربع مجموعات أحرف:
- الأحرف الكبيرة: string.ascii_uppercase
- الأحرف الصغيرة: string.ascii_lowercase
- الأرقام: string.digits
- الرموز الخاصة: string.punctuation

يستخدم البرنامج secrets.choice() لاختيار الأحرف وsecrets.SystemRandom().shuffle() لترتيبها بمصدر عشوائية النظام. لا يستخدم random لتوليد كلمات المرور.

يختار البرنامج أولاً حرفاً واحداً على الأقل من كل مجموعة مطلوبة، ثم يكمل بقية الطول من جميع الأحرف، ثم يخلط الترتيب. لذلك يضمن أن كل كلمة مرور مولدة تحتوي على المجموعات الأربع.

الطول المقبول من 4 إلى 4096 حرفاً، وعدد الكلمات في التشغيل الواحد من 1 إلى 50.

## 3. حساب SHA-256

تعتمد الدالة على:

    hashlib.sha256(text.encode("utf-8")).hexdigest()

تكون قيمة SHA-256 بطول 256 بت، أي 32 بايت، وتمثيلها الست عشري 64 خانة.

### قيمة مرجعية معروفة

للنص abc تكون قيمة SHA-256:

    ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad

كما اختُبر نص عربي غير حساس، وكانت النتيجة في تشغيل Windows:

    a433fb4c622953583421726d62fd046612be73116e5584f98da7f4853bca307b

## 4. واجهة الاستخدام

توليد كلمة مرور بطول 16:

    python password_tool.py generate

توليد ثلاث كلمات مرور بطول 20:

    python password_tool.py generate --length 20 --count 3

حساب SHA-256 للنص abc:

    python password_tool.py hash "abc"

حساب SHA-256 لنص عربي:

    python password_tool.py hash "الأمن السيبراني"

عرض المساعدة:

    python password_tool.py --help

## 5. نتائج التشغيل الفعلية على Windows

نفّذ الطالب الأوامر التالية في Windows PowerShell:

- python password_tool.py --help
- python -m py_compile password_tool.py tests\test_password_tool.py
- python -m unittest discover -s tests -v
- python password_tool.py generate
- python password_tool.py generate --length 20 --count 3
- python password_tool.py hash "abc"
- python password_tool.py hash "الأمن السيبراني"

النتائج:
- عرضت واجهة المساعدة أوضاع generate وhash.
- اكتمل فحص Python Compilation دون ظهور خطأ.
- اجتازت اختبارات الوحدة الستة عشر جميعها.
- ولّد البرنامج كلمة مرور تجريبية واحدة بطول 16.
- ولّد البرنامج ثلاث كلمات مرور تجريبية، طول كل منها 20 حرفاً.
- أعادت دالة SHA-256 قيمة abc المرجعية المعروفة.
- نجح حساب SHA-256 لنص عربي بعد UTF-8، وأنتج قيمة Hexadecimal من 64 خانة.

لا يتضمن هذا التقرير قيم كلمات المرور التي ظهرت في نافذة PowerShell؛ فقد حُذفت من التوثيق لتجنب نشر أسرار يمكن إعادة استخدامها. يجب اعتبار أي كلمة مرور ظهرت في سجل أو لقطة منشورة مكشوفة وعدم استخدامها لحساب حقيقي.

## 6. نتائج اختبارات الوحدة على Windows

النتيجة الفعلية التي ظهرت في PowerShell:

    Ran 16 tests in 0.005s

    OK

- الاختبارات الناجحة: 16.
- الاختبارات الفاشلة: 0.
- الاختبارات المتخطاة: 0.

تغطي الاختبارات مطابقة طول كلمة المرور، ووجود الأحرف الكبيرة والصغيرة والأرقام والرموز، واستخدام مجموعة الأحرف المسموح بها، وقبول الحد الأدنى للطول، ورفض الأطوال والأنواع غير الصحيحة، وتوليد العدد المطلوب، ورفض العدد غير الصالح، ومطابقة قيم SHA-256 المرجعية للنص abc والنص الفارغ، ودعم النص العربي، ورفض الإدخال غير النصي.

## 7. احتياطات أمنية وحدود

1. كلمة المرور المولدة تظهر على الشاشة؛ لا تلتقط صورة أو تحفظ مخرجات تحتوي على كلمة مرور فعلية تستخدمها لحساب حقيقي.
2. SHA-256 تجزئة أحادية الاتجاه وليست تشفيراً؛ لا توجد عملية فك تشفير تعيد النص الأصلي.
3. لا ينبغي تخزين كلمات مرور المستخدمين بواسطة SHA-256 مباشرة في نظام إنتاجي. استخدم Argon2id أو scrypt أو bcrypt مع ملح فريد وإعدادات مناسبة.
4. تمرير كلمات مرور حقيقية كوسائط سطر أوامر قد يكشفها في سجل الأوامر أو قائمة العمليات؛ استخدم نصوصاً تجريبية فقط مع أمر hash.
5. لا يخزن البرنامج كلمات المرور أو يرسلها عبر الشبكة.

## 8. الخلاصة

ينفذ المشروع متطلبات التكليف باستخدام secrets لتوليد كلمات مرور آمنة تحقق فئات الأحرف الأربع، وhashlib.sha256() لحساب تجزئة النصوص بعد ترميز UTF-8. اجتاز فحص الصياغة والاختبارات الستة عشر على Windows، كما نجحت تجارب التوليد المخصص وحساب SHA-256 للنص الإنجليزي والعربي. تم توضيح الفرق بين التجزئة والتشفير والتنبيه إلى أن SHA-256 وحده ليس مناسباً لتخزين كلمات مرور المستخدمين في بيئة إنتاجية.
