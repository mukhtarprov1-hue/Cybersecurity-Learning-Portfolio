# التقرير العملي — التكليف الثامن
## أداة مولد كلمات السر وحساب التجزئة SHA-256
**Password Generator & SHA-256 Hasher**

**لغة البرمجة:** Python  
**الاستخدام:** أداة تعليمية محلية لأمن المعلومات  
**الاعتماديات:** مكتبات Python القياسية فقط.

## 1. الهدف

تطوير برنامج يقدم خدمتين: توليد كلمات مرور عشوائية آمنة تشفيرياً بمجموعات أحرف متنوعة وطول يحدده المستخدم، وحساب قيمة SHA-256 لنص UTF-8 وعرضها بصيغة Hexadecimal.

## 2. مولد كلمات المرور

يعتمد البرنامج على أربع مجموعات أحرف:
- الأحرف الكبيرة: string.ascii_uppercase
- الأحرف الصغيرة: string.ascii_lowercase
- الأرقام: string.digits
- الرموز الخاصة: string.punctuation

يستخدم البرنامج secrets.choice() لاختيار الأحرف وsecrets.SystemRandom().shuffle() لترتيبها بمصدر عشوائية النظام. لا يستخدم random لتوليد كلمات المرور.

لا يكتفي البرنامج بالاختيار من المجموعة الكاملة؛ بل يختار أولاً حرفاً واحداً على الأقل من كل مجموعة مطلوبة، ثم يكمل بقية الطول من جميع الأحرف، ثم يخلط الترتيب. لذلك يضمن أن كل كلمة مرور مولدة تحتوي على المجموعات الأربع.

الطول المقبول من 4 إلى 4096 حرفاً، وعدد الكلمات في التشغيل الواحد من 1 إلى 50.

## 3. حساب SHA-256

تعتمد الدالة على:

    hashlib.sha256(text.encode("utf-8")).hexdigest()

خطوات العمل:
1. استلام النص.
2. تحويله إلى Bytes باستخدام UTF-8.
3. حساب SHA-256.
4. استخراج القيمة بصيغة Hexadecimal.

تكون قيمة SHA-256 بطول 256 بت، أي 32 بايت، وتمثيلها الست عشري 64 خانة.

### مثال تحقق معروف

للنص abc تكون قيمة SHA-256:

    ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad

ويستخدم الاختبار هذه القيمة المرجعية، إضافة إلى اختبار النص الفارغ والنص العربي.

## 4. واجهة الاستخدام

توليد كلمة مرور بطول 16:

    python password_tool.py generate

توليد كلمة مرور بطول 24:

    python password_tool.py generate --length 24

توليد ثلاث كلمات مرور بطول 20:

    python password_tool.py generate --length 20 --count 3

حساب SHA-256 للنص abc:

    python password_tool.py hash "abc"

عرض المساعدة:

    python password_tool.py --help

## 5. اختبارات الوحدة

تغطي مجموعة الاختبارات:
- مطابقة الطول المطلوب.
- وجود الأحرف الكبيرة والصغيرة والأرقام والرموز.
- الاقتصار على مجموعة الأحرف المسموح بها.
- قبول الحد الأدنى للطول.
- رفض الأطوال غير الصالحة والأنواع غير الصحيحة.
- توليد العدد المطلوب من كلمات المرور.
- رفض عدد كلمات مرور غير صالح.
- مطابقة SHA-256 للنص abc مع قيمة مرجعية معروفة.
- مطابقة SHA-256 للنص العربي بعد UTF-8.
- مطابقة قيمة SHA-256 للنص الفارغ.
- رفض الإدخال غير النصي لدالة التجزئة.

## 6. احتياطات أمنية وحدود

1. كلمة المرور المولدة تظهر على الشاشة؛ لا تلتقط صورة أو تحفظ مخرجات تحتوي على كلمة مرور فعلية تستخدمها لحساب حقيقي.
2. SHA-256 تجزئة أحادية الاتجاه وليست تشفيراً؛ لا توجد عملية فك تشفير تعيد النص الأصلي.
3. لا ينبغي تخزين كلمات مرور المستخدمين بواسطة SHA-256 مباشرة في نظام إنتاجي. استخدم Argon2id أو scrypt أو bcrypt مع ملح فريد وإعدادات مناسبة.
4. تمرير كلمات مرور حقيقية كوسائط سطر أوامر قد يكشفها في سجل الأوامر أو قائمة العمليات؛ توثق الأمثلة نصوصاً تجريبية فقط.
5. لا يخزن البرنامج كلمات المرور أو يرسلها عبر الشبكة.

## 7. الخلاصة

ينفذ المشروع متطلبات التكليف باستخدام secrets لتوليد كلمات مرور آمنة تحقق فئات الأحرف الأربع، وhashlib.sha256() لحساب تجزئة النصوص بعد ترميز UTF-8. ويعرض واجهة أوامر واضحة واختبارات تتحقق من شروط كلمة المرور ومن صحة قيم SHA-256 المرجعية. تم توضيح الفرق بين التجزئة والتشفير والتنبيه إلى أن SHA-256 وحده ليس مناسباً لتخزين كلمات مرور المستخدمين في بيئة إنتاجية.
