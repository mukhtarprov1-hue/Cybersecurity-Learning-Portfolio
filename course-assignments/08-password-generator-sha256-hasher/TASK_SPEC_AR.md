# التكليف الثامن: أداة مولد كلمات السر وحساب التجزئة
## Password Generator & SHA-256 Hasher

**مسار البرمجة:** الأمن السيبراني — Python

## 1. الوصف العام

كتابة سكريبت بلغة Python يقدم وظيفتين أمنيتين:
1. توليد كلمات مرور عشوائية قوية تتضمن أحرفاً كبيرة وصغيرة وأرقاماً ورموزاً خاصة باستخدام مصدر عشوائية آمن تشفيرياً.
2. حساب قيمة التجزئة SHA-256 لنص يحدده المستخدم، وعرض القيمة بصيغة Hexadecimal.

## 2. خطوات الإنجاز

1. إنشاء دالة لتوليد كلمات مرور بطول يحدده المستخدم.
2. تجميع مجموعات الأحرف باستخدام string.ascii_uppercase وstring.ascii_lowercase وstring.digits وstring.punctuation.
3. استخدام مكتبة secrets بدلاً من random في اختيار الأحرف وترتيبها.
4. ضمان وجود حرف واحد على الأقل من كل مجموعة مطلوبة.
5. إنشاء دالة لحساب SHA-256 باستخدام hashlib.sha256().
6. ترميز النص إلى UTF-8 قبل تمريره إلى دالة التجزئة.
7. استخراج قيمة التجزئة باستخدام hexdigest() وعرضها بصيغة Hexadecimal.
8. اختبار صحة التوليد والتجزئة باستخدام اختبارات قابلة لإعادة التشغيل.

## 3. معايير القبول

- طول كلمة المرور يطابق الطول المطلوب.
- تضم كلمة المرور حرفاً كبيراً وحرفاً صغيراً ورقماً ورمزاً خاصاً على الأقل.
- استخدام secrets كمصدر عشوائية آمن وعدم الاعتماد على random.
- رفض الأطوال والقيم غير الصالحة برسالة واضحة.
- حساب SHA-256 بصورة صحيحة.
- إظهار قيمة التجزئة بصيغة Hexadecimal مكونة من 64 خانة.
- دعم النصوص التي تحتوي على Unicode عبر UTF-8.
- توفير توثيق واختبارات لنتائج التوليد والتجزئة.

## 4. ملاحظة أمنية تعليمية

SHA-256 دالة تجزئة أحادية الاتجاه وليست تشفيراً قابلاً لفك التشفير. استخدام SHA-256 مباشرة لتخزين كلمات مرور المستخدمين في الأنظمة الإنتاجية غير مناسب؛ ينبغي استخدام خوارزميات مخصصة لتجزئة كلمات المرور مثل Argon2id أو scrypt أو bcrypt مع أملاح فريدة وإعدادات عمل مناسبة. يطبق هذا التكليف SHA-256 لأنه المطلوب للتدريب على مفهوم التجزئة.
