# التكليف الثاني عشر: نظام رفع الملفات الآمن والتحقق متعدد الطبقات

**المسار:** البرمجة للأمن السيبراني — Web & PHP  
**نوع الوثيقة:** تفريغ منظم لمتطلبات التكليف المرسلة في Discord، مع الحفاظ على معناها.

## 1. الوصف العام

تطوير برنامج خادم بلغة PHP يستقبل الملفات المرفوعة ويطبق استراتيجية الدفاع متعدد الطبقات (Defence in Depth)، بهدف تقليل مخاطر رفع Web Shells والتلاعب بالامتدادات وثغرات Path Traversal.

## 2. خطوات التنفيذ المطلوبة

1. استقبال الملف من حقل $_FILES['file_uploaded'] والتحقق من الحجم الأقصى المسموح.
2. استخدام قائمة مسموحات صارمة (Whitelist) للامتدادات، مثل PDF وPNG وJPG.
3. فحص نوع MIME الفعلي باستخدام مكتبة PHP Fileinfo، وعدم الاعتماد على الترويسات التي يرسلها المتصفح.
4. استخراج الامتداد باستخدام pathinfo($filename, PATHINFO_EXTENSION).
5. توليد اسم تخزين عشوائي باستخدام bin2hex(random_bytes(16)).
6. نقل الملف المقبول باستخدام move_uploaded_file() إلى مجلد تخزين مخصص وتأمين صلاحياته.

## 3. معايير القبول

- رفض الملفات الخبيثة أو المتلاعب بامتداداتها، مثل إعادة تسمية ملف PHP إلى .jpg.
- توليد اسم تخزين آمن عشوائي.
- نقل الملفات المسموح بها بنجاح إلى مجلد التخزين المخصص.
- تقليل مخاطر Path Traversal وعدم استخدام اسم العميل بوصفه مساراً على الخادم.

## 4. توضيحات المصطلحات

- finfo هو امتداد/واجهة PHP لفحص نوع MIME من محتوى الملف.
- الدالة الصحيحة لنقل الملف المرفوع هي move_uploaded_file().
- الاسم العشوائي الناتج عن bin2hex(random_bytes(16)) يتكون من 32 خانة سداسية عشرية، أي 128 بت عشوائياً قبل إضافة الامتداد.

> لا يتضمن النص المستلم تحديد حجم أقصى رقمي أو قائمة امتدادات نهائية؛ لذلك اختير حد تعليمي قدره 2 MiB وقائمة PDF/PNG/JPG/JPEG، وتم توضيح هذين القرارين في التقرير بدلاً من نسبتهما إلى نص المدرب.
