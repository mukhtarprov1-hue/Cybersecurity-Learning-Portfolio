# ملاحظات التحليل الأمني — التكليف 12

## الأصول والأخطار

| الأصل | الخطر | التحكم المطبق |
|---|---|---|
| ملف الرفع المؤقت | تمرير ملف محلي بدلاً من HTTP upload | is_uploaded_file() |
| مساحة التخزين | تنفيذ أو تنزيل ملف مرفوع عبر الويب | تخزين خارج public/ وعدم إنشاء رابط تنزيل |
| نوع الملف | تزوير الامتداد أو ترويسة المتصفح | Whitelist + Fileinfo MIME + فحص التوقيع |
| موارد الخادم | ملفات ضخمة أو صور ذات أبعاد مبالغ فيها | حد 2 MiB وحد 40 مليون بكسل |
| مسار الملف | Path Traversal أو استبدال ملفات | اسم عشوائي مستقل عن اسم المستخدم |
| جلسة الرفع | Cross-Site Request Forgery | Session CSRF token وSameSite cookie |
| معلومات الخادم | تسريب المسارات والاستثناءات | رسالة عامة وسجل داخلي مختصر |

## ماذا يمنع هذا التنفيذ؟

- امتدادات غير مسموحة مثل .php.
- ملف PHP عادي أعيدت تسميته إلى .jpg، لأن MIME المكتشف لا يطابق image/jpeg.
- ملفات يتجاوز حجمها الحد أو لا تتطابق أحجامها الفعلية والمعلنة.
- ملفات صور لا تتوافق مع نوع الصورة المحدد أو تتجاوز حد الأبعاد.
- أسماء تخزين تتحكم بها مدخلات المستخدم؛ الاسم الأصلي لا يستخدم في المسار.
- وصول HTTP المباشر إلى الملفات المخزنة عبر DocumentRoot لأن مجلد التخزين شقيق لـ public/ وليس داخله.

## ما الذي لا يثبته هذا الحل؟

فحص MIME والتوقيع ليس ماسحاً للبرمجيات الخبيثة. قد تحوي ملفات PDF صالحة شكلياً على JavaScript أو روابط أو مرفقات نشطة. كما يمكن أن توجد ملفات Polyglot أو ثغرات في مكتبات تحليل المحتوى. يجب ألا تعرض الخدمة الملفات المرفوعة مباشرة؛ وأي ميزة تنزيل لاحقة يجب أن تتطلب تفويضاً صريحاً وتستخدم Content-Disposition: attachment وX-Content-Type-Options: nosniff.

للإنتاج، أضف خدمة فحص برمجيات خبيثة معزولة أو CDR، حصصاً لكل مستخدم، معدل طلبات، مراقبة، نسخاً احتياطية، وحساب خدمة محدود الصلاحيات. لا تعتبر PHP built-in server بيئة نشر إنتاجية.

## ملاحظة حول الصلاحيات

على Linux/macOS، يطبق البرنامج صلاحيات 0700 للمجلد و0600 للملف. على Windows لا تكافئ chmod() أذونات POSIX بشكل كامل؛ لذلك يجب ضبط NTFS ACL يدوياً بحيث يكون حساب خدمة PHP وحده قادراً على القراءة والكتابة، مع وصول مسؤول النظام عند الحاجة.
