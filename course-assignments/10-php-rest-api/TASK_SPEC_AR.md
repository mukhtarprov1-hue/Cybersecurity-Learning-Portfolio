# التكليف العاشر: أداة معالجة طلبات HTTP وبناء REST API باستخدام PHP

## الوصف العام

تطوير واجهة REST API بلغة PHP تستقبل طلبات HTTP وتتعامل مع طرق `GET` و`POST` و`PUT` و`DELETE`، وتقرأ Headers وJSON Body، ثم تعيد استجابات JSON منظمة مع أكواد HTTP صحيحة.

## متطلبات المدرب الأساسية

1. تعيين ترويسة الاستجابة `Content-Type: application/json`.
2. قراءة طريقة الطلب من `$_SERVER['REQUEST_METHOD']`.
3. قراءة ترويسات الطلب باستخدام `getallheaders()` مع مسار توافق احتياطي.
4. قراءة جسم الطلب عبر `php://input` ثم تحليله بواسطة `json_decode()`.
5. التمييز بين طرق HTTP الأربع ومعالجة كل طريقة بشكل صحيح.
6. إرسال أكواد الحالة المناسبة وطباعة استجابة JSON منسقة.

## التوسعات التقنية المضافة

- REST CRUD حقيقي على المورد `/api/items` بدلاً من ردود ثابتة.
- مسار صحة `/api/health`.
- مصادقة Bearer للعمليات المعدّلة للبيانات باستخدام `hash_equals()`.
- تحقق صارم من نوع المحتوى وصحة JSON والحقول والأطوال وUTF-8.
- حد أقصى لحجم الطلب 64 KiB.
- أكواد تفصيلية: 201 و204 و400 و401 و404 و405 و413 و415 و422 و503.
- ترويسات أمنية ومعرّف طلب فريد `X-Request-ID`.
- سياسة CORS تعتمد قائمة سماح صريحة.
- تخزين JSON بآلية قفل وكتابة مؤقتة ثم استبدال.
- سجل تدقيق JSONL لا يحفظ التوكن أو جسم الطلب.
- اختبارات آلية وسير CI على Windows وUbuntu.

## المخرجات

- كود PHP مقسم إلى طبقات واضحة.
- اختبارات آلية قابلة للتشغيل دون Composer.
- توثيق عربي وعقد API وملاحظات أمنية.
- سكريبت PowerShell لتجربة CRUD.
- صور تنفيذ أصلية من جهاز الطالب.
