# حالة التكليف 10 — المتطلبات الأساسية والتطويرات اللاحقة

## الخلاصة

**المطلوب الأساسي من المدرب جاهز ومتحقق منه محليًا.** توجد إضافة تقنية لاحقة لسلسلة تدقيق HMAC داخل الفرع، ويجب التعامل معها كتطوير اختياري قيد الاستكمال، لا كشرط لقبول التكليف الأساسي.

لم تُحذف أي ملفات أو أكواد تخص هذا التطوير. بقيت كما هي حتى يمكن استكمالها لاحقًا.

## ب. تطوير لاحق اختياري — HMAC-Chained Audit Trail

**الحالة: تطوير إضافي قيد الاستكمال؛ لم يُعتمد كميزة نهائية مكتملة.**

أُضيف هذا التطوير بعد تنفيذ المطلوب الأساسي، ويشمل:

- src/AuditChain.php
- src/AuditLogger.php
- tools/audit_verify.php
- tests/audit_integrity.php
- scripts/load-audit-key.ps1
- docs/AUDIT_CHAIN_FORMAT.md

الغرض منه ربط أحداث سجل التدقيق باستخدام HMAC-SHA256، والتحقق من تعديل السجلات أو إعادة ترتيبها أو حذف سجل داخلي.

### ما الذي تحقق منه؟

- اختبارات التكامل المنفصلة للسلسلة: **9/9 ناجحة محليًا على Windows باستخدام PHP 8.5.12**، ورمز الخروج 0.
- اجتازت الاختبارات التسعة كذلك مصفوفة GitHub Actions على Windows/Ubuntu وPHP 8.2/8.5.
- هذه الاختبارات تعمل على بيانات مؤقتة معزولة؛ نجاحها لا يثبت وحده اكتمال دورة التشغيل الفعلية للتطوير الإضافي.

### ما الذي لا يزال مطلوبًا قبل اعتبار التطوير مكتملًا؟

1. تحميل مفتاح HMAC محليًا من الملف الخارجي عبر scripts/load-audit-key.ps1 دون كشف المفتاح.
2. تشغيل API وإنتاج أحداث فعلية في storage/audit-chain.jsonl.
3. تشغيل php tools/audit_verify.php على سجل التشغيل الفعلي والتحقق من النتيجة.
4. توثيق دورة التشغيل كاملة بالأدلة المحلية.
5. توثيق حدود التطوير وعدم وصفه بأنه tamper-proof.

**هذا التطوير غير مطلوب لاعتبار REST API الأساسي منجزًا.** لا تحذف ملفاته أو اختباراته أو سجلاته بسبب كونه ما زال قيد التطوير.

## ج. ملفات التشغيل المحلية

الملفات التالية ناتجة عن تشغيل التطوير وليست مصدرًا برمجيًا مطلوبًا للتسليم:

- storage/audit-chain.jsonl
- storage/audit-chain.jsonl.lock

تُستثنى هذه الملفات من Git في .gitignore الخاص بفرع التكليف 10. احتفظ بها محليًا عند الحاجة إلى مواصلة الاختبار، ولا ترفعها إلى المستودع؛ فقد تتضمن بيانات وصفية عن طلبات التشغيل.

ملف مفتاح HMAC محفوظ خارج المستودع في ملف المستخدم .assignment10-audit-hmac.key. لا ترفعه أو تضع قيمته في الصور أو السجلات.
