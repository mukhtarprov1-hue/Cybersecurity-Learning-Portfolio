# Assignment 10 — Screenshot Evidence

Capture genuine PowerShell output and HTTP responses from the learner's own Windows machine. Never expose the real API token in screenshots; use a temporary lab token and crop/clear the variable-setting command.

Recommended files:

1. `01-php-version-and-help.png` — PHP version and endpoint/run instructions.
2. `02-health-get.png` — GET /api/health response.
3. `03-post-create.png` — authenticated POST returning 201 and Location.
4. `04-get-and-put.png` — retrieve and update an item.
5. `05-delete-204.png` — DELETE returning 204.
6. `06-errors-and-security.png` — 401/405/415 or invalid JSON handling.
7. `07-unit-tests.png` — all PHP tests passing.
8. `08-audit-log.png` — JSONL audit metadata without Authorization/body content.

Use a training token only. Do not publish secrets or personal data.
