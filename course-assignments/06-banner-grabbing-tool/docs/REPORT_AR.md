# التقرير العملي — التكليف السادس

## أداة جلب بصمات الخدمات والخدمات المتفاعلة (Banner Grabbing Tool)

**المسار:** البرمجة للأمن السيبراني — Python  
**نوع الأداة:** TCP Service Banner Collection

## 1. مقدمة

يهدف المشروع إلى جمع معلومات تعريفية عن خدمات TCP التي تستمع على منافذ محددة، وذلك بالاتصال بالخدمة وقراءة الرسالة الترحيبية التي ترسلها أو إرسال طلب مناسب عندما تكون الخدمة تفاعلية. من أمثلة الخدمات التي ترسل Banner فورياً SSH وFTP، بينما تتطلب خوادم الويب طلب HTTP مثل \`HEAD\` قبل إرسال الاستجابة.

تُستخدم النتائج في أعمال الاستطلاع الأمني المصرح بها لفهم نوع الخدمة والمنتج والإصدار عندما تفصح الخدمة عن هذه البيانات.

## 2. أهداف التنفيذ

1. إنشاء اتصال TCP بخدمة على منفذ يحدده المستخدم.
2. استقبال البانر الفوري من الخدمات التي ترسل رسالة ترحيب.
3. إرسال طلب \`HEAD / HTTP/1.1\` إلى منافذ HTTP المحددة.
4. دعم HTTPS اختيارياً عبر TLS قبل إرسال طلب HEAD.
5. استقبال 1024 بايت كحد أقصى من البيانات باستخدام \`recv(1024)\`.
6. فك ترميز البيانات باستخدام UTF-8 مع تجاهل البايتات غير الصالحة.
7. تنظيف النص واستخراج السطر الأول الرئيسي باستخدام \`splitlines()[0]\`.
8. إظهار البانر أو ترويسة \`Server\` أو توضيح عدم وجود Banner، مع التعامل مع Timeout ورفض الاتصال.

## 3. تصميم البرنامج

### 3.1 تحديد الهدف والمنافذ

تتحقق \`validate_target()\` من أن قيمة الهدف غير فارغة ولا تحتوي على محارف تحكم أو مسافات قد تسبب إدخالاً غير آمن في ترويسة HTTP. وتحوّل \`parse_ports()\` قائمة المنافذ والنطاقات مثل \`21,22,80,8000-8002\` إلى قائمة أرقام فريدة ضمن النطاق 1–65535. يحد البرنامج عدد المنافذ في التشغيل الواحد إلى 256.

### 3.2 الاتصال بخدمة TCP

تستخدم \`grab_banner()\` الدالة \`socket.create_connection()\` للاتصال بالهدف والمنفذ المحددين مع مهلة زمنية. عند نجاح الاتصال لا يعني ذلك أن الخدمة سترسل Banner؛ لذلك توجد حالة مستقلة \`NO_BANNER\` للخدمة التي تقبل الاتصال ثم تصمت أو تغلق الاتصال دون بيانات.

### 3.3 الخدمات ذات البانر الفوري

في خدمات مثل SSH وFTP ينتظر البرنامج البيانات الأولية من الخادم مباشرةً. مثال Banner محتمل لخادم SSH:

\`\`\`text
SSH-2.0-OpenSSH_9.6
\`\`\`

يعرض البرنامج السطر الأول كما استلمه، ولا يدّعي صحة إصدار غير موجود في النص.

### 3.4 الخدمات التفاعلية — HTTP

عند وجود المنفذ في مجموعة HTTP المحددة، يرسل البرنامج طلباً أساسياً:

\`\`\`http
HEAD / HTTP/1.1
Host: 127.0.0.1
User-Agent: Authorized-Banner-Grabber/1.0
Accept: */*
Connection: close
\`\`\`

ثم يستقبل استجابة الخادم. قد يكون السطر الأول مثلاً \`HTTP/1.1 200 OK\`، ويمكن استخراج ترويسة \`Server\` إن أرسلها الخادم. لا يرسل البرنامج طلب HTTP إلى جميع المنافذ؛ يرسل HEAD فقط للمنافذ المحددة في \`--http-ports\` أو \`--https-ports\`.

### 3.5 دعم HTTPS

تستخدم منافذ HTTPS المحددة اتصال TLS أولاً، مع التحقق من الشهادة افتراضياً. يمكن تعطيل التحقق بواسطة \`--no-verify-tls\` في مختبر مصرح يستخدم شهادة ذاتية التوقيع، ولا يوصى بذلك في الاستخدام الإنتاجي.

### 3.6 معالجة النصوص

تطبق \`decode_banner()\` متطلب الورقة:

\`\`\`python
raw_data.decode('utf-8', errors='ignore')
\`\`\`

ثم تزيل محارف التحكم غير القابلة للطباعة مع الإبقاء على الأسطر الجديدة والتبويبات، وتستخرج السطر الأول من خلال:

\`\`\`python
lines = filtered.splitlines()
first_line = lines[0].strip() if lines else ""
\`\`\`

### 3.7 حالات النتائج والمهلة

| الحالة | التفسير |
|---|---|
| \`BANNER_FOUND\` | تم استلام بيانات نصية قابلة للعرض. |
| \`NO_BANNER\` | تم قبول TCP لكن لم يصل Banner، أو أغلق الطرف الاتصال دون بيانات، أو تعذر إكمال تبادل TLS/HTTP. |
| \`CLOSED\` | رفض الطرف الاتصال صراحةً. |
| \`TIMEOUT\` | انتهت مهلة إنشاء اتصال TCP قبل نجاحه. |
| \`BLOCKED\` | منع نظام التشغيل أو سياسة أمنية محلية محاولة الاتصال. |
| \`ERROR\` | خطأ اتصال آخر غير مصنف. |

الفصل بين \`NO_BANNER\` و\`CLOSED\` مهم: الخدمة التي تقبل الاتصال ثم لا ترسل بيانات ليست بالضرورة خدمة مغلقة.

## 4. بيئة ومتطلبات التشغيل

- Python 3.10 أو أحدث موصى به.
- مكتبات Python القياسية فقط: \`socket\`, \`ssl\`, \`argparse\`, \`ipaddress\`, \`time\`, \`dataclasses\`.
- لا توجد تبعيات خارجية.
- يجب إجراء الاختبارات على جهاز أو مختبر مصرح به.

## 5. طريقة التشغيل

\`\`\`powershell
python banner_grabber.py --help
python banner_grabber.py 127.0.0.1
python banner_grabber.py 127.0.0.1 --ports 21,22,80,443,8080,8443

## 6. خطة الاختبار

تستخدم الاختبارات خوادم TCP مؤقتة مرتبطة بعنوان \`127.0.0.1\`، ولا تتصل بأهداف خارجية. تشمل الاختبارات الإحدى عشرة: تحليل المنافذ، رفض المدخلات غير الصحيحة، التحقق من الهدف، تنظيف UTF-8، Banner فوري لـ SSH وFTP، طلب HTTP HEAD، حالة عدم وجود Banner، مهلة القراءة، رفض الاتصال، ومهلة إنشاء اتصال TCP.

## 7. نتائج التحقق في بيئة إعداد المشروع

- اجتاز \`py_compile\` دون أخطاء.
- نجحت الاختبارات الإحدى عشرة دون إخفاقات في بيئة إعداد المشروع (Python 3.13.5).
- تم اختبار SSH وFTP وHTTP باستخدام مستمعات محلية مؤقتة.

هذه نتائج بيئة إعداد المشروع وليست نتائج تشغيل على جهاز Windows الخاص بالطالب. تضاف نتائج Windows الفعلية بعد تشغيل المشروع محلياً.

## 8. حدود الحل

- يفحص TCP فقط ولا ينفذ UDP Banner Grabbing.
- يستقبل حتى 1024 بايت فقط، وفق متطلب التكليف.
- بعض الخدمات لا ترسل Banner قبل طلب بروتوكولي خاص؛ الأداة تدعم HTTP HEAD فقط من الطلبات التفاعلية في هذه النسخة.
- ترويسة \`Server\` اختيارية وقد يحذفها الخادم أو يغيرها.
- Banner قد يكون مخفياً أو معدلاً أو مضللاً، لذلك لا يمثل إثباتاً قطعياً لنظام التشغيل أو إصدار البرنامج.
- يجب الاقتصار على الأنظمة المملوكة أو التي يوجد تصريح صريح بفحصها.

## 9. الخلاصة

ينفذ المشروع جمع بصمات خدمات TCP من خلال الاتصال بالمنافذ المحددة، والتعامل مع البانر الفوري لخدمات مثل SSH/FTP، وإرسال HTTP HEAD للخدمات التفاعلية، واستقبال البيانات وتنظيفها وفك ترميزها، ثم عرض السطر الرئيسي أو حالة عدم وجود Banner. كما يوفر معالجة واضحة للمهلات ورفض الاتصال وإغلاق الموارد.
