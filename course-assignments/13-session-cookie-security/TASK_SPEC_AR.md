# التكليف الثالث عشر: أداة إدارة الجلسات والكوكيز المحمية

**المسار:** البرمجة للأمن السيبراني — Web & PHP

## الوصف العام

تطوير برنامج PHP لإدارة الجلسات والكوكيز بشكل آمن، وتقليل مخاطر سرقة Session IDs وهجمات XSS وCSRF، باستخدام خصائص HttpOnly وSecure وSameSite، وتجديد معرف الجلسة بعد الدخول.

## خطوات التكليف

1. ضبط خصائص كوكي الجلسة قبل استدعاء session_start() باستخدام session_set_cookie_params() ومصفوفة الخيارات.
2. تفعيل httponly => true لمنع JavaScript من قراءة كوكي الجلسة عبر document.cookie.
3. استخدام samesite => 'Strict' لتقليل إرسال الكوكي في الطلبات العابرة للمواقع.
4. تفعيل secure => true لحصر إرسال الكوكي عبر HTTPS.
5. تجديد معرف الجلسة بعد تسجيل الدخول باستخدام session_regenerate_id(true) للحد من Session Fixation.
6. إنشاء واجهة تقارن الكوكيز الآمنة وغير الآمنة وتوضح ما يستطيع document.cookie قراءته.
7. فحص ترويسات Set-Cookie والتحقق من HttpOnly وSecure وSameSite.

## معايير القبول

- إصدار كوكي يحمل HttpOnly والتحقق من عدم ظهوره في document.cookie.
- إصدار كوكي آمن يحمل Secure وSameSite=Strict.
- تجديد معرف الجلسة بعد الدخول.
- استمرار الجلسة المصادق عليها عند الانتقال بين الصفحات.
- إنهاء الجلسة بشكل صحيح عند تسجيل الخروج.

## توضيح أمني

HttpOnly يمنع قراءة قيمة الكوكي عبر JavaScript، لكنه لا يمنع XSS من تنفيذ طلبات باسم المستخدم. وSameSite=Strict لا يغني عن CSRF token. يجب استخدام HTTPS في بيئة الإنتاج حتى تكون خاصية Secure فعالة.
