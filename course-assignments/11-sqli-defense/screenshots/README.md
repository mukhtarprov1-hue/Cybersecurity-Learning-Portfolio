# Evidence Images — Assignment 11

تم إنشاء صور الأدلة الخمس بواسطة سكربت التحقق المحلي بعد تشغيل التطبيق والاختبارات على Windows. تحفظ السجلات التفصيلية في `../evidence/local-verification/`، ويسجل ملف `evidence/local-verification/SHA256SUMS.txt` بصمات SHA-256 للملفات.

| الملف | نوع الدليل وما يثبته |
|---|---|
| `01-php-runtime-and-sqlite-extension.png` | عرض مرئي لمخرجات أوامر PHP الفعلية: الإصدار وملف INI والامتدادات ومشغلات PDO. ليس تصويراً مباشراً لنافذة PowerShell. |
| `02-safe-normal-search.png` | لقطة متصفح من التطبيق المحلي: البحث عن `alice` في الوضع الآمن يعيد سجلاً واحداً. |
| `03-unsafe-sqli-demonstration.png` | لقطة متصفح من التطبيق المحلي: الحمولة التعليمية في الوضع غير الآمن تعرض السجلات الاصطناعية الخمسة. |
| `04-safe-sqli-blocked.png` | لقطة متصفح من التطبيق المحلي: الحمولة نفسها في الوضع الآمن تعيد صفر سجلات. |
| `05-automated-tests.png` | عرض مرئي لمخرجات الاختبارات الفعلية: ستة اختبارات ناجحة وصفر فشل. ليس تصويراً مباشراً لنافذة PowerShell. |

## قواعد التعامل مع الأدلة

- لا تعدّل نتائج الاختبارات أو أعداد السجلات.
- احتفظ بالسجلات النصية إلى جانب الصور.
- لا تُظهر مفاتيح أو بيانات شخصية أو ملفات خارج المشروع.
- أي إعادة تحقق لاحقة يجب أن تحدّث `docs/LOCAL_VERIFICATION_REPORT.md` وملف البصمات `evidence/local-verification/SHA256SUMS.txt`.
- صور المتصفح تعكس صفحات التطبيق المحلي على `127.0.0.1`، أما صور runtime والاختبارات فهي عرض منسق لمخرجات الأوامر المسجلة.
