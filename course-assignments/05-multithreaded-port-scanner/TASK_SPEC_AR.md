# نص التكليف الأصلي — التكليف الخامس

**المسار:** البرمجة للأمن السيبراني — Python  
**عنوان التكليف:** أداة فحص المنافذ متعددة الخيوط (Multithreaded Port Scanner)

> هذا الملف تفريغ نصي من ورقة التكليف المرفقة المكوّنة من صفحة واحدة، مع الحفاظ على أقسامها ومتطلباتها. لا يحل محل ملف المدرب الأصلي.

## 1. الوصف العام للتكليف

المطلوب هو تطوير سكريبت بلغة Python يهدف إلى فحص منافذ الشبكة لعنوان IP محدد لاكتشاف الخدمات النشطة. يقوم السكريبت باستخدام مكتبة Sockets مع تقنية المعالجة المتعددة (Multithreading) لتسريع فحص نطاق واسع من المنافذ وإظهار المنافذ المفتوحة بدقة ودون تأخير.

## 2. خطوات إنجاز التكليف

1. إنشاء دالة فحص لمقبس شبكي تستقبل عنوان `Target IP` ورقم المنفذ.
2. ضبط وقت المهلة (`Timeout`) للمقبس لضمان عدم تعليق السكريبت عند فحص المنافذ المغلقة.
3. استخدام مكتبة `concurrent.futures` لإطلاق مجموعة من الخيوط المتوازية (`Threads`).
4. تمرير قائمة المنافذ المطلوبة (مثل 1 إلى 1024) على الخيوط بالتوازي.
5. طباعة المنافذ المفتوحة فور اكتشافها مع إمكانية عرض الوقت المستغرق في عملية الفحص.

## 3. الأدوات والحيل المساعدة

- استخدام `ThreadPoolExecutor(max_workers=50)` لتسريع عملية الفحص بشكل كبير.
- الدالة `connect_ex` التي ترجع القيمة `0` عند نجاح الاتصال وفتح المنفذ.

## 4. معايير قبول الحل

- نجاح السكريبت في اكتشاف المنافذ المفتوحة والمغلقة بدقة وفي زمن قياسي.
- عدم انهيار السكريبت (`No Crashes`) عند التعامل مع العناوين غير المستجيبة مع إغلاق المقابس بنجاح.

---

**ملاحظة نطاق:** الورقة تصف اكتشاف المنافذ المفتوحة/المغلقة والخدمات النشطة. هذا البرنامج ينفذ TCP connect scanning ويحدد حالة اتصال المنفذ؛ لا ينفذ تحليل banner أو تحديد إصدار الخدمة. ولا يُستنتج أن المنفذ مغلق عند مجرد انتهاء المهلة.
