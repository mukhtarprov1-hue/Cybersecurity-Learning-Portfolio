# Genuine Windows execution screenshots

Place original, unaltered screenshots captured on the learner's Windows machine in this folder. Do not create images that imitate terminal output.

Recommended files:

1. `01-help.png` — `python port_scanner.py --help`.
2. `02-local-scan.png` — completed authorized scan and summary.
3. `03-unit-tests.png` — updated unit-test output (`OK`, with an environment-related skip if applicable).
4. `04-pycompile.png` — successful `py_compile` command.
5. `05-listening-services.png` — `Get-NetTCPConnection -State Listen` and, where appropriate, process/service identification.

The learner previously created an `img/` directory in a separate local copy. Those image bytes were not attached to this conversation and therefore are not included in this GitHub commit. They can be copied into this folder after cloning and then committed from the learner's machine.
