# Learning Roadmap

This roadmap is an organizational guide, not a claim that the following topics have already been studied or completed. Add a project only after doing the work and recording evidence.

## Suggested progression

1. **Programming and tooling:** C fundamentals, Python basics, Git, command-line use, and reproducible builds.
2. **Networking foundations:** addressing, switching, routing, common protocols, and packet analysis in authorized labs.
3. **Operating systems:** Linux and Windows fundamentals, permissions, processes, logs, and system troubleshooting.
4. **Defensive security:** asset inventory, secure configuration, logging, detection concepts, and incident documentation.
5. **Application security:** input validation, authentication concepts, safe testing of deliberately vulnerable local applications, and remediation notes.
6. **Automation and analysis:** parsing data, test automation, simple detections, and concise technical reports.

## Evidence standard

For each completed item, record the objective, environment, actions, expected result, observed result, artifacts, limitations, and next step. Do not describe a planned activity as completed.
