# Security Policy

## Scope

This is a public educational portfolio. It is not advertised as a production security product. Do not test against systems you do not own or have explicit permission to assess.

## Reporting an issue

For a vulnerability in the code contained here, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the maintainer through a trusted private channel. Do not include real credentials, personal data, or exploit details for third-party systems in a public issue.

## Secrets policy

Never place real passwords, access tokens, API keys, private keys, recovery codes, or private course links in commits, screenshots, test fixtures, or issue discussions. Treat any accidentally exposed credential as compromised and rotate it immediately.
