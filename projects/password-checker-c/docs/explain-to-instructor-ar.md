# نقاط لشرح Password Checker أمام المدرب

## شرح مختصر

«هذا برنامج تأسيسي بلغة C يختبر كلمة المرور وفق خمسة شروط محددة: طول أكبر من 8 أحرف، وحرف إنجليزي كبير، وحرف صغير، ورقم، ورمز. أقرأ الإدخال باستخدام `fgets()`، وأستخدم دوال `ctype.h` لتصنيف المحارف، ثم أستخدم `&&` للتأكد من تحقق الشروط الخمسة معًا. أضفت اختبارات لحالات القبول والرفض وحدّ الإدخال الطويل.»

## أهم الدوال

- `fgets()`: قراءة نص إلى مخزن ذي حجم محدد.
- `strlen()`: حساب طول النص.
- `strcspn()`: تحديد موضع نهاية السطر لإزالتها.
- `isupper()` و`islower()`: البحث عن الحروف الكبيرة والصغيرة.
- `isdigit()`: فحص الأرقام.
- `ispunct()`: فحص علامات الترقيم التي نستخدمها هنا كرموز.
- `&&`: اشتراط تحقق كل الشروط قبل القبول.

## عرض عملي

1. ترجم البرنامج باستخدام أمر البناء في README.
2. شغّل الاختبارات بأمر Python الموجود في README.
3. وضّح أن `Abcdef12!` عينة قبول وأن `Abcdef123` عينة رفض لغياب الرمز.
4. أظهر حالة تجاوز 255 حرفًا لتوضيح التعامل مع الإدخال الطويل.

استخدم العينات الموجودة في المستودع فقط. لا تدخل كلمة مرور حقيقية.
